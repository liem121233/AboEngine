# AboEngine — Phase 1

Lightweight browser-based 2D game engine foundation.

## Requirements

- Node.js 20+ recommended
- A modern browser with WebGL2

## Install

```bash
npm install
```

## Run development server

```bash
npm run dev
```

Open the local URL shown by Vite.

## Build

```bash
npm run build
```

## Phase 1 features

- Editor layout
- WebGL2 renderer
- Scene
- GameObject
- Transform
- Hierarchy
- Inspector
- Create GameObject
- Edit X/Y/Z/rotation/scale
- Play / Stop foundation
- Keyboard / mouse input foundation

The next phase should only begin after Phase 1 is verified.
